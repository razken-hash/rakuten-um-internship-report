\chapter*{Glossary}

\begin{description}
    \item[\textbf{\acf{API}}]
    A set of rules and interfaces that allows different software applications or services to communicate and exchange data.

    \item[\textbf{GitHub Actions}]
    A continuous integration and continuous delivery (CI/CD) platform provided by GitHub that automates tasks such as building, testing, and deploying applications through configurable workflows.

    \item[\textbf{\acf{GCS}}]
    A cloud-based object storage service provided by Google Cloud Platform for storing and retrieving files and other digital objects at scale.

    \item[\textbf{\acf{MD}}]
    A lightweight markup language used to format structured text using simple syntax. It is commonly used for documentation, README files, and automatically generated reports.

    \item[\textbf{\acf{MCP}}]
    An open protocol that enables AI assistants to interact with external tools and structured data sources. In this project, the Storybook MCP server allows AI assistants to query Storybook stories, component metadata, and APIs.

    \item[\textbf{Next.js}]
    A React-based web framework for building modern web applications, providing features such as server-side rendering, static generation, routing, and API integration.

    \item[\textbf{Node.js}]
    A JavaScript runtime environment based on Google's V8 engine that allows JavaScript and TypeScript applications to execute outside a web browser, particularly on servers.

    \item[\textbf{pnpm}]
    A fast and disk-efficient JavaScript package manager used to install, manage, and share dependencies across projects, particularly monorepos.

    \item[\textbf{Proxy}]
    An intermediary server that receives client requests and forwards them to another service or resource. In this project, the proxy provides controlled access to private Google Cloud Storage objects.

    \item[\textbf{\acf{SSR}}]
    A rendering technique in which the HTML of a web page is generated on the server before being sent to the client's browser.

    \item[\textbf{Storybook}]
    An open-source development and documentation environment for building, testing, and documenting UI components in isolation.
\end{description}
