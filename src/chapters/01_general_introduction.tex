\chapter*{General Introduction}
\addcontentsline{toc}{chapter}{General Introduction}

\indent As part of my six-month final-year internship, I joined Rakuten France’s IT department as a Frontend Developer Intern within the Architecture team.

This team focuses on ensuring the scalability and consistency of the platform’s architecture by designing technical solutions, contributing to DevOps initiatives, supporting development teams, and building reusable components for various microfrontend applications across the platform.

My work began by implementing the platform’s dark mode through a shared component repository, integrating it across multiple applications, updating legacy libraries and optimizing initial page load performance, which gave me a valuable opportunity to explore the platform’s codebase in depth. I then worked on improving application quality by implementing visual regression testing using Reg-Viz, adding end-to-end tests with Playwright and mocks, and setting up GitHub Actions pipelines for CI/CD automation. This involved developing a proxy application to secure access to Google Cloud Storage, providing an opportunity to manage the full software lifecycle from development through to deployment. Finally, I explored AI-assisted development practices, including MCP integrations with tools such as Storybook, Playwright, Chromium, and GitHub, as well as agentic development approaches.

This internship represented a real immersion into the professional world, allowing me to apply in a concrete way the technical skills acquired during my studies. Working on real use cases with well-defined business challenges helped me strengthen my knowledge in frontend development, gain a better understanding of best practices in code quality, testing, and maintenance, and develop a clearer awareness of professional expectations in terms of rigor, autonomy, and teamwork.

The main objective of this internship was to become familiar with frontend development practices in a professional environment and to actively contribute to real-world projects. This report outlines my journey, the skills I developed, and how I achieved these objectives.
